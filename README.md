# Sheng Ji Teacher

An interactive game that teaches players how to play Sheng Ji (升级).

## Goal

Build a web app where beginners can learn Sheng Ji through:
- interactive tutorials
- practice scenarios
- playing against AI opponents

## Rules Version

This app follows:
- 4 players
- 2 decks
- 4 jokers
- 108 cards total
- Each player starts with 25 cards
- The "it" player receives 8 bottom cards
